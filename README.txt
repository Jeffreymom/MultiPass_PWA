실행 방법
1. 압축을 풉니다.
2. index.html을 더블클릭합니다.
3. 또는 VS Code에서 폴더를 열고 Go Live를 실행합니다.

수록 자료
- 공개 기출: 43회
- 전체 문제: 3,440문항
- 기간: 2002.12.08 ~ 2022.03.05
- 최신 출제기준: 2025.1.1.~2027.12.31.

주요 기능
- 현재 출제범위 집중학습
- 4과목별 20문제 학습
- 최신 기준 80문제 모의고사
- 43회분 연도별 원문 기출
- 즉시 정답 확인
- 오답노트 자동 저장
- 즐겨찾기
- 과목별 점수 및 합격권 판정
- 모바일/PC 반응형
- 인터넷 없이 실행 가능

주의
- 문제와 정답은 업로드된 공개 기출 PDF 원문을 기준으로 추출했습니다.
- 현재/보조/검토/제외 상태는 2025~2027 출제기준과 키워드를 대조한 자동 분류입니다.
